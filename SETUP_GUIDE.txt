🔧 ВСТАНОВЛЕННЯ
═════════════════════════════════════════════════

1. Встановіть залежності:
   pip install -r requirements.txt

2. Встановіть змінні оточення в .env файл:
   BOT_TOKEN=your_token_here
   API_NINJAS_KEY=your_key_here

3. Переконайтеся, що файл sportbot.db присутній або буде створений


▶️ ЗАПУСК БОТА
═════════════════════════════════════════════════

python bot.py

Бот почнеться слухати повідомлення користувачів від Telegram.


✅ ПЕРЕВІРКА РОБОТИ МАГАЗИНУ
═════════════════════════════════════════════════

1. Запустіть бот та напишіть команду:
   /shop

2. Мають з'явитися:
   ✓ Баланс монет
   ✓ 17 товарів розділені на 7 категорій
   ✓ Кнопки для купівлі для кожного товара

3. Кліцніть на будь-який товар

4. Очікувані результати:
   ✓ Якщо баланс достатній:
     - Монети віднімаються
     - Товар додається в інвентар
     - Показується персоналізоване повідомлення
   
   ✓ Якщо баланс недостатній:
     - Алерт про недостатньо монет
     - Баланс залишається без змін
   
   ✓ Якщо перевищено лімит (для бустів):
     - Алерт про максимум покупок
     - Баланс залишається без змін

5. Перевіріть покупки:
   /wallet
   
   Мають з'явитися всі куплені товари з датою покупки

🎮 ПРИКЛАД ВИКОРИСТАННЯ
═════════════════════════════════════════════════

Користувач:
  1. /start
  2. Отримує 100 монет на старт
  3. /shop
  4. Бачить 17 товарів
  5. Клікає "⚡ 60 · Премiум тренування"
  6. Отримує тренування
  7. Баланс змінюється з 100 на 40
  8. /wallet
  9. Бачить "Премiум тренування" з датою покупки


🐛 РОЗВ'ЯЗАННЯ ПРОБЛЕМ
═════════════════════════════════════════════════

Проблема: "BOT_TOKEN is not set"
  Рішення: Встановіть змінну оточення BOT_TOKEN

Проблема: Бот не відповідає
  Рішення: Переконайтеся, що bot.py запущений

Проблема: Покупки не зберігаються
  Рішення: Перевірте, чи файл sportbot.db доступний

Проблема: Товари не показуються
  Рішення: Перевірте, чи SHOP_ITEMS не пустий в bot.py
