# MyTelegramBot 🏋️

Розумний Telegram бот для відстеження фізичних тренувань, управління профілем та магазину нагород з монетною системою.

## 🚀 Можливості

- 📊 **Відстеження тренувань** - логування вправ та їх результатів
- 👤 **Профіль користувача** - інформація про зріст, вагу, вік та цілі
- 🎯 **Щоденні завдання** - система щоденних тренувальних цілей
- 🛒 **Магазин** - покупка преміум тренувань та бонусів за монети
- 💪 **Мотивація** - мотиваційні цитати та виклики
- 🌍 **Двомовність** - українська та англійська мови
- 💾 **Стійка база даних** - оптимізована SQLite з режимом WAL

## 📋 Вимоги

- Python 3.8+
- SQLite3 (включена в Python)

## 🔧 Встановлення

### 1. Клонувати репозиторій

```bash
git clone https://github.com/VolodymyrMishchenko98/MyTelegramBotv.3-main
cd MyTelegramBotv.3-main
```

### 2. Створити віртуальне середовище

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Встановити залежності

```bash
pip install -r requirements.txt
```

### 4. Налаштувати змінні середовища

```bash
# Скопіювати приклад конфігурації
cp .env.example .env

# Відредагувати .env та додати свої значення
```

### 5. Отримати необхідні ключі

#### 🤖 Токен Telegram Bot

1. Відкрийте Telegram та знайдіть [@BotFather](https://t.me/botfather)
2. Напишіть `/newbot` та дотримуйтесь інструкцій
3. Скопіюйте отриманий токен у `.env`

#### 🔑 API Ninjas Key (для інформації про калорії)

1. Перейдіть на [api.api-ninjas.com](https://api.api-ninjas.com/)
2. Створіть акаунт та отримайте API ключ
3. Додайте ключ у `.env`

### 6. Запустити бота

```bash
python bot.py
```

## 🎮 Основні команди бота

| Команда         | Опис                                 |
| --------------- | ------------------------------------ |
| `/start`        | Почати роботу з ботом                |
| `/profile`      | Подивитися профіль користувача       |
| `/edit_profile` | Відредагувати профіль                |
| `/workout`      | Додати тренування                    |
| `/shop`         | Відкрити магазин товарів             |
| `/wallet`       | Подивитися інвентар та монети        |
| `/daily`        | Виконати щоденне завдання            |
| `/reset`        | Очистити всі дані профілю            |
| `/goal`         | Встановити тижневу мету              |
| `/set_language` | Вибрати мову (українська/англійська) |

## 🗄️ База даних

Бот використовує SQLite з оптимізованою конфігурацією:

- **Режим WAL** - для паралельних операцій
- **Глобальне з'єднання** - уникає race conditions
- **Потокобезпечність** - працює з asyncio
- **Автоматичні транзакції** - атомарність операцій

## 🐛 Вирішення проблем

### "ModuleNotFoundError: No module named 'aiogram'"

Переконайтесь, що ви встановили залежності:

```bash
pip install -r requirements.txt
```

### "BOT_TOKEN is not set"

Перевірте, що файл `.env` існує та містить правильний токен:

```bash
cat .env
```

### БД заблокована

Це нормально при високому навантаженню. Бот автоматично повторює операцію з таймаутом 10 секунд.
